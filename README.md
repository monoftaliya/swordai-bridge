# SwordAI Bridge

Мост между **ChatGPT** и вашим собственным телефоном **Android**. ChatGPT (через протокол
MCP) может видеть экран телефона, читать уведомления и выполнять действия — нажатия,
прокрутку, ввод текста, открытие приложений — **даже когда приложение ChatGPT закрыто**.
Телефон держит постоянное соединение с облачным сервером (Cloud Bridge); ChatGPT обращается
к серверу, сервер передаёт команду на телефон, телефон выполняет и возвращает результат.

Проект состоит из двух частей:

| Часть | Технологии | Папка |
|-------|-----------|-------|
| **SwordAI Android Agent** | Kotlin, Jetpack Compose, Material 3, Accessibility Service, MediaProjection, Foreground Service, OkHttp WebSocket | [`android/`](android/) |
| **SwordAI Cloud Bridge** | Python, Starlette (ASGI), официальный MCP SDK, WebSocket, OAuth 2.1, SQLite / PostgreSQL | [`server/`](server/) |

## Как это работает (коротко)

```
┌──────────┐   MCP/HTTPS    ┌──────────────────┐   WSS (команда,    ┌─────────────────┐
│ ChatGPT  │ ─────────────▶ │   Cloud Bridge   │ ── подпись ECDSA ─▶│  Android Agent  │
│ (MCP)    │ ◀───────────── │  (Python/ASGI)   │ ◀── результат ──── │  (ваш телефон)  │
└──────────┘   результат    └──────────────────┘                    └─────────────────┘
      OAuth 2.1 (вход + согласие)      │  SQLite/PostgreSQL              │ Accessibility
                                       │  журнал, устройства,           │ MediaProjection
                                       │  токены, аудит                 │ подтверждения
```

1. ChatGPT вызывает MCP-инструмент (например `get_screen_info`).
2. Сервер проверяет OAuth-токен и область доступа, формирует команду, **подписывает** её
   закрытым ключом (ECDSA P-256) и отправляет на телефон по защищённому WebSocket.
3. Телефон **проверяет подпись** (закреплённый открытый ключ), проверяет отсутствие повтора,
   при необходимости **спрашивает подтверждение у пользователя**, выполняет действие и
   возвращает результат.
4. Сервер отдаёт результат ChatGPT.

Подробная архитектура — в [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Быстрый старт

### 1. Поднять Cloud Bridge
Проще всего — бесплатный тариф **Render** + бесплатная БД **Neon** (PostgreSQL) по готовому
`render.yaml`. Можно и локально (SQLite). Полная инструкция: [`docs/DEPLOY.md`](docs/DEPLOY.md).

```bash
# Локальный запуск для разработки (из папки server/)
cd server
pip install -r requirements.txt
PUBLIC_URL=http://localhost:8000 ADMIN_PASSWORD=change-me python -m bridge
# Откройте http://localhost:8000/admin
```

### 2. Собрать APK
Своего компьютера для сборки **не требуется** — можно собрать в облаке через **GitHub
Actions** (workflow уже в репозитории). Либо локально в **Android Studio**. Инструкция и
нюансы установки (sideload, Android 13+): [`docs/BUILD_APK.md`](docs/BUILD_APK.md).

### 3. Связать телефон с сервером
В админ-панели нажмите «Создать код пэйринга», введите код в приложении на телефоне.
Устройство получает уникальный токен и закрепляет открытый ключ сервера.

### 4. Подключить ChatGPT
Добавьте MCP-сервер по адресу `https://<ваш-сервер>/mcp`, пройдите вход (OAuth) и согласие.
Нюансы тарифов и ограничения: [`docs/CHATGPT.md`](docs/CHATGPT.md).

## Безопасность — что заложено

Проект построен вокруг жёстких ограничений (подробно в [`docs/SECURITY.md`](docs/SECURITY.md)):

- **Команды только от своего сервера.** Телефон проверяет ECDSA-подпись каждой команды и
  закрепляет открытый ключ сервера. Неподписанные/чужие команды отбрасываются.
- **Никакого произвольного кода.** Сервер может прислать только одну из фиксированных
  инструкций со строго проверяемыми аргументами — не исполняемый код.
- **Работа видна.** Постоянное уведомление, экранный индикатор активности, журнал действий.
  Приложение себя не скрывает.
- **Пароли и секреты не перехватываются.** Поля ввода пароля блокируются, коды/карты в
  уведомлениях маскируются.
- **Защита банковских и чувствительных приложений не обходится.** Для них действия
  блокируются или требуют подтверждения.
- **Значимые действия — только с подтверждением** на самом телефоне.
- **Аварийная остановка** — кнопка в приложении, действие в уведомлении, плитка в шторке,
  экранная «СТОП», удалённая пауза с сервера. Возобновление — только с телефона.
- **Системные разрешения Android, блокировка экрана и защита приложений не обходятся.**
