# Сборка APK

Есть два пути: **без своего компьютера** (сборка в облаке GitHub Actions) и **на компьютере**
(Android Studio). Для повседневного использования приложения компьютер не нужен — он нужен
только один раз, чтобы получить APK.

---

## Путь A. GitHub Actions — без компьютера

В репозитории уже есть workflow `.github/workflows/android.yml`. Он собирает отладочный и
релизный APK и выкладывает их в артефакты запуска.

### Шаги
1. Загрузите этот репозиторий в свой GitHub (через веб-интерфейс: *Add file → Upload files*,
   или импортом).
2. Откройте вкладку **Actions** → workflow **«Android APK»** → **Run workflow**.
3. Дождитесь завершения (10–40 минут при первом запуске из-за скачивания зависимостей).
4. В странице запуска, раздел **Artifacts**, скачайте **`swordai-bridge-apk`**. Внутри —
   `app-debug.apk` и `app-release.apk`.

Workflow также:
- запускает юнит-тесты ядра (`testDebugUnitTest`) — если подпись/политика сломаны, сборка
  упадёт;
- гоняет lint информационно (не блокирует сборку);
- складывает отчёты в артефакт `reports`.

### Какой APK ставить
- **`app-debug.apk`** — проще всего для личного теста. Подписан отладочным ключом.
- **`app-release.apk`** — если не задан свой ключ, он **тоже** подписывается отладочным ключом
  (устанавливается, но не предназначен для публикации). Для «настоящей» подписи см. ниже.

### Своя подпись релиза (необязательно)
Создайте keystore и добавьте секреты репозитория (*Settings → Secrets and variables →
Actions*):

```bash
# создать ключ (один раз), запомните пароли и alias:
keytool -genkeypair -v -keystore release.jks -alias swordai \
  -keyalg RSA -keysize 2048 -validity 10000

# превратить в base64 для секрета:
base64 -w0 release.jks   # (на macOS: base64 release.jks | tr -d '\n')
```

Секреты:
| Секрет | Значение |
|--------|----------|
| `SWORDAI_KEYSTORE_BASE64` | вывод `base64` от `release.jks` |
| `SWORDAI_KEYSTORE_PASSWORD` | пароль хранилища |
| `SWORDAI_KEY_ALIAS` | `swordai` (ваш alias) |
| `SWORDAI_KEY_PASSWORD` | пароль ключа |

Если `SWORDAI_KEYSTORE_BASE64` задан, workflow подпишет релиз вашим ключом; иначе — отладочным.

## Путь B. Android Studio — на компьютере

1. Установите **Android Studio** (актуальную версию с AGP 8.13+).
2. Откройте папку **`android/`** как проект. Gradle сам подтянет зависимости (нужен интернет).
3. Для отладочного APK: **Build → Build Bundle(s)/APK(s) → Build APK(s)**. Готовый файл —
   `android/app/build/outputs/apk/debug/app-debug.apk`.
4. Для релиза со своим ключом задайте переменные окружения перед запуском Gradle:
   `SWORDAI_KEYSTORE_PATH`, `SWORDAI_KEYSTORE_PASSWORD`, `SWORDAI_KEY_ALIAS`,
   `SWORDAI_KEY_PASSWORD`, затем `./gradlew assembleRelease`.

Из командной строки (без студии, но с Android SDK):
```bash
cd android
./gradlew testDebugUnitTest   # прогнать тесты ядра
./gradlew assembleDebug       # собрать debug APK
```

### Параметры проекта
- `compileSdk` / `targetSdk` = **36**, `minSdk` = **26** (Android 8.0+).
- Kotlin 2.2.20, Compose BOM 2025.09.00, AGP 8.13.0, Gradle 8.14.3 (wrapper в репозитории).
- JVM target 17.

## Установка APK на телефон (sideload)

1. Перенесите APK на телефон (кабель, облако, прямое скачивание из артефактов GitHub).
2. Откройте файл и разрешите установку из этого источника, когда система спросит.
3. Запустите приложение и выдайте доступы на экране «Разрешения» (см. [PERMISSIONS.md](PERMISSIONS.md)).

### Важные нюансы Android
- **Android 13+ «Ограниченные настройки».** Для приложений, установленных не из магазина,
  система может блокировать включение **Accessibility**. Если переключатель неактивен:
  *Настройки → Приложения → SwordAI Bridge → ⋮ (меню) → «Разрешить ограниченные настройки»*,
  затем включите Accessibility.
- **Захват экрана** требует согласия **каждую** сессию — это поведение Android, не ошибка.
- **Автозапуск после перезагрузки** и стабильность фона зависят от производителя (MIUI, EMUI и
  т.п. часто требуют вручную разрешить автозапуск и снять ограничения батареи). Проект это
  честно оговаривает и не обещает абсолютной непрерывности.
- **Проверка разработчиков для sideload.** Google анонсировал постепенное введение требования
  верификации разработчиков для установки приложений вне магазина (поэтапно, начиная с
  2026–2027 по регионам). По состоянию на начало 2026 года детали и сроки менялись —
  **проверьте актуальные требования** для вашего региона и версии Android. Для личной установки
  на своё устройство, как правило, остаются пути (в т.ч. установка через ADB). Если установка
  обычным способом заблокирована:
  ```bash
  adb install app-debug.apk
  ```

## Частые проблемы
- **Сборка в Actions упала на зависимостях** — повторите запуск (иногда таймауты сети Maven).
- **«App not installed»** — уже стоит версия с другой подписью; удалите старую и поставьте заново.
- **Accessibility не включается** — см. «Ограниченные настройки» выше.

После получения APK переходите к [DEPLOY.md](DEPLOY.md) (поднять сервер) и
[CHATGPT.md](CHATGPT.md) (подключить ChatGPT).
